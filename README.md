# Dave Harwin Nueva – CC101 Personal Portfolio

## Included files
- `index.html` – portfolio with personal information, education, skills, and CC102 Java project
- `style.css` – responsive styling
- `SwimmingTracker.java` – submitted Java source code

## Before publishing
1. Review all details for accuracy.
2. Add your GitHub profile URL after creating your account.
3. Add an email address only if you want it visible publicly.
4. Add earlier schools if your instructor requires a complete education history.
5. Open `index.html` in a browser and test the navigation and Java download link.

## Publish with GitHub Pages
1. Sign in at https://github.com/ and create a new **public** repository named `my-personal-portfolio`.
2. Upload `index.html`, `style.css`, `SwimmingTracker.java`, and `README.md` to the repository's root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. After publishing, your website address will look like:
   `https://YOUR-USERNAME.github.io/my-personal-portfolio/`
7. Submit your public repository URL through CC101 Go.

The GitHub Pages website URL and repository URL are different. Your instructor specifically asks for the public repository link.
